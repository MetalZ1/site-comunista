# Site Comunista - Frente Aberta

## 🚀 Como executar o site localmente

### Opção 1: Usando o arquivo INICIAR_SITE.bat (Recomendado)

1. **Duplo-clique no arquivo INICIAR_SITE.bat**
2. Uma janela do terminal vai abrir
3. Abra seu navegador e vá para: http://localhost:8000
4. Pronto! O site está funcionando

Para parar o servidor, pressione CTRL+C na janela do terminal.

### Opção 2: Manualmente via PowerShell

Se o arquivo .bat não funcionar:

\\\powershell
cd C:\Users\mat_a\site-comunista
python -m http.server 8000
\\\

Depois abra no navegador: http://localhost:8000

## 📁 Estrutura do projeto

- index.html - Página principal
- quiz.html - Página do quiz
- style.css - Estilos
- dados.json - Conteúdo (edite aqui!)
- js/app.js - Lógica do site
- js/quiz.js - Lógica do quiz

## ✏️ Como editar

Edite o arquivo dados.json com qualquer editor de texto. Recarregue o navegador (F5) para ver as mudanças.

## 🎯 Funcionalidades

- 6 páginas (Início, Direita e Esquerda, Sobre, Reflexão, Recursos, Vídeos)
- Pop-up ao entrar no site
- Quiz com 5 perguntas
- Sistema de resultado personalizado
